# Англо-русский словарь
### Проект на C++17 с применением ООП

**Автор:** nwaezeezinne86-prog  
**Курс:** ППОИС  
**Дата:** Сентябрь 2026

---

## Цель проекта

Разработка консольного англо-русского словаря
на современном C++17 с профессиональным
процессом разработки на GitHub.

### Функции
- Добавление / поиск / удаление слов
- Несколько переводов для одного слова
- Указание части речи
- Сохранение и загрузка из файла
- Поиск по русскому переводу
- Подсчёт количества слов
